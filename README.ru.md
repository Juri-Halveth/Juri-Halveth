# Juri Janovski / Juri Halveth · HALVETH VERACHEL STUDIOS

**Краткий путеводитель по проекту · EN / RU**

Публичный профиль GitHub связывает разработку программ, системную интеграцию, обеспечение качества, исследования безопасности, доказательные системы и интерактивные миры с конкретными репозиториями и образцами работ. Ссылки портфолио ведут к реестрам проектных материалов и проверок.

Частные сертификаты работ HALVETH описывают конкретные артефакты, версии источников и проверки. Они не являются институциональными персональными квалификациями и не предоставляют сертификацию ISTQB. Каждый образец работы следует читать в пределах его документированного объёма.

Этот путеводитель составлен и отредактирован вручную по проверенному источнику. Исходная техническая документация остаётся справочным материалом для команд, требований сборки, точных версий и подробных проверок.
