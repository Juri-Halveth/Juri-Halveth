## Was konkret vorliegt

Native Softwareintegration in Morrowind/OpenMW, ein geprüfter lokaler Patch, automatisierte Zustands- und Gegenproben, erfolgreiche GitHub-Workflows, Lernplattform-Code und reproduzierbare Quellen-/Verzweigungsmodelle. Jede Aussage verweist auf einen bestimmten Quellstand oder Ergebnisbeleg.

Ein bewusst gesetzter Stopppunkt vor einer Auswirkung bleibt als Stopppunkt dokumentiert. Beobachtete Fähigkeiten, bedingte Auswirkungen, Präventionswert und externe Anerkennung werden getrennt beschrieben. Nicht ausgeführt bedeutet weder widerlegt noch automatisch nachgewiesen.

## Benchmarks richtig lesen

Die neun Referenzrahmen machen fachliche Anknüpfungen und nächste Leistungsnachweise sichtbar. Die Unterlagen vergeben keine Abschlüsse der genannten Herausgeber. KI-Unterstützung und individueller Beitrag sind im Kurzprofil erläutert.

## Lokal prüfen

```powershell
python scripts/verify_portfolio.py
python examples/branch_models.py --depth 4
```

Die Befehle benötigen Python 3.11 oder neuer und keine zusätzlichen Pakete. Der Prüfer liest nur diesen Portfolioordner. Das endliche Beispiel braucht keine Spielinstallation und keinen Netzwerkzugriff.
